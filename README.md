# GymLog — Dark Mode 12-Week Aesthetic Tracker (Profile: 22M, ~89 kg, 5.62 ft)

Minimalistic dark-mode workout, posture/core, cardio, steps, and Sunday body-weight tracker built for GitHub Pages and iPhone Safari Home Screen.

## Profile Calibrations Included
- **Zone 2 Heart Rate (Age 22):** 118–138 bpm
- **Daily Steps (Auto-Scales by Week):** 7,000 (Wks 1–4) → 8,500 (Wks 5–8) → 10,000 (Wks 9–12)
- **Cardio Specs:** Brisk incline walk (4.5–5.6 km/h, 4–9% incline) & stationary cycle (70–85 RPM, optional Sat intervals in Wks 9–12)
- **Workout:** 6-day Aesthetic V-Taper + Anti-Slouch PPL split (broad lateral/rear delts, upper-chest priority, core stability + hanging knee raises, athletic legs)
- **Sunday Weigh-In:** Calibrated for 89.0 kg starting baseline

## Deploy on GitHub Pages
1. Unzip this archive.
2. Create a public GitHub repository and upload **all files from inside the unzipped folder** into the repo root.
3. Go to **Settings → Pages**, deploy from branch `main` (`/ root`), and save.
4. Open the live URL in **Safari on iPhone** → **Share → Add to Home Screen → Add**.
